Approve edits to published text

The brain owns the words on the site, so it can fix them — but a correction has to be told apart from a bug in the generator, because to the parity check they look the same. So every change to a body the site already publishes is approved here, one at a time, against its diff (ADR-0006).

Below is every page whose text now differs from the copy captured when the section was ingested. Read the diff, name the issue that decided it, and approve. The approval covers exactly that wording: edit the page again and it comes back here for a second look. Only the facilitator can approve. On the command line the same thing is make brain-approve-edit.
