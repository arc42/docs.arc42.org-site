The other half of [[tip-3-7]], and the reason that tip carries two tags: grouping neighbours is
allowed only if the grouping rule is stated. "You should explicitly state these criteria" — the
tip then lists five usable ones, so the reader is not left to invent a rule and leave it
implicit.

Not to be confused with the term [[decision-criteria]], which is about weighing alternatives in
section 9. This facet is about making any rule visible, whatever it decides.
