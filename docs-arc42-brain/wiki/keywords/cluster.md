For readers whose context diagram has outgrown the page. [[tip-3-7]] is the only page the site
marks this way, and its advice is to combine neighbours that share data, a use case, a
technology, an organisation or a task — with the grouping shown as a stereotype so that a reader
can see it is a group. The neighbouring tips do the same thing without the label:
[[tip-3-6]] calls it categorization, [[tip-3-8]] does it with ports.

A facet rather than a concept: what is clustered stays whatever it was.
