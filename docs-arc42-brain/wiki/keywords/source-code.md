For readers who want to know what belongs in a document and what is better read in the code.
The pages under this facet argue in both directions: refer to the code instead of repeating it
([[tip-4-4]]), or write down what the code cannot say.

This is a facet, not a concept: arc42 defines no term "source code", it only keeps taking a
position on how close the documentation should sit to it.
