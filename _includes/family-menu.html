{%- comment -%} The "42" family menu: a small button in the masthead and the popover it opens, listing the sibling sites from _data/family.yml. Prototyped here first, to be carried to arc42.org, req42.de and systems42.org. The markup follows systems42's family-menu.html so the component stays the same family-wide; only the colours are this site's own. Contract with assets/js/site.js ("Family menu"): a .family-toggle button whose aria-controls names the panel, and the panel carrying the `hidden` attribute while closed. Without JavaScript the button does nothing — the same links are always reachable in the footer. {%- endcomment -%}
