Falls back to site.icons so a byline without its own hash still gets the project accounts. author optional — name, folded into each link's accessible label so a screen-reader user hears whose GitHub this is, and so two bylines on one page do not produce two links called "GitHub". Changes from the FontAwesome version: · Every glyph now comes from assets/icons/ui.svg via icon.html. Each link is icon-only, so each one passes `label` — an unlabelled icon link announces as its bare href, and four of them in a row announce as nothing useful at all. The labels are built with `capture` rather than written inline, because Jekyll's include tag does NOT interpolate Liquid inside a quoted parameter value: label="GitHub{{ who }}" would emit those six characters literally. · The dev.to entry used to be UNCONDITIONAL and hardcoded to a single person's profile, so every author on the site was credited with Gernot Starke's dev.to account. It is behind a key now like the rest. · `devto` and `dev` are both accepted: _config.yml spells it `devto`, the old template looked for `dev`. · There is no Twitter/X entry. The sprite has no such glyph, and site.icons's twitter handle points at a service the project does not post to; Mastodon is the account that is actually maintained.
