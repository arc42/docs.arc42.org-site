{%- comment -%} Article header — title, tags, byline. Used by the page / post / doc-section layouts for tips and examples. Parameters page required — the page or post object to render. link optional — true to make the title a link to the item itself. level optional — heading level, default 1. Two things changed here beyond the markup: · TAGS ARE NOW LINKS TO THE KEYWORD INDEX. They used to point at /search/?t=, a client-side query that renders nothing without JavaScript and cannot be linked to or bookmarked meaningfully. The site already publishes a server-rendered index of every tip by keyword at /keywords/, where _pages/keywords.html emits `id="{{ tag | cgi_escape }}"` for each one — hence the cgi_escape here, so the fragment matches the id it is aiming at. A tag sat inches from that page for years without being able to reach it. · FontAwesome is gone. Every glyph comes from the sprite via icon.html. {%- endcomment -%} {%- assign article = include.page -%} {%- assign hlevel = include.level | default: 1 -%}
